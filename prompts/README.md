# Prompts Directory

This directory contains strategic context information that can be provided to Claude to help it make better gameplay decisions.

## Structure

- **`town-descriptions/`** - Detailed descriptions of towns in Pokemon Red, including key locations, NPCs, and available actions

## Usage

These descriptions can be loaded and included in Claude's context when the AI reaches specific locations. This helps the agent:

- Understand what's possible in each area
- Make strategic decisions about where to go
- Know which NPCs to interact with
- Plan ahead for objectives
